# HVAC Sensor Validation & Metrology

A reproducible engineering case study for characterization, calibration, independent validation, dynamic-response analysis, stability assessment, measurement-uncertainty evaluation, and compliance-oriented interpretation of an HVAC relative-humidity sensor.

## Project Scope

This repository is the analyst-side workspace for a structured sensor-metrology study. It focuses on the evidence available to an analyst and intentionally excludes hidden simulator truth.

The project addresses:
- dataset qualification and experimental-design traceability
- static measurement error and bias
- repeatability and reproducibility
- hysteresis and temperature influence
- calibration model development
- independent blind validation
- dynamic step response
- ramp, cyclic, and sinusoidal tracking behavior
- stability and drift
- measurement uncertainty
- final engineering assessment against stated requirements

## Dataset Provenance

The analyzed measurements are generated by a separate virtual sensor-metrology laboratory that models a controlled HVAC humidity-sensor validation campaign. The resulting analyst-facing release is frozen as `VSM-LAB-DATA-v1` before downstream analysis begins.

The synthetic dataset is designed to preserve realistic experimental structure, repeated measurements, environmental factors, dynamic behavior, aging behavior, and measurement variability while keeping hidden simulator truth outside the analyst repository.

## Analytical Boundary

The analyst does not use hidden DUT personality parameters, injected truth components, latent simulator states, or exact hidden error mechanisms.

A key metrology principle throughout the project is:

`RH_Reference != exact physical truth`

The reference instrument is itself a measurement system with finite uncertainty.

## Engineering Workflow

`Data Qualification -> Static Characterization -> Calibration -> Independent Validation -> Dynamic Characterization -> Stability / Drift -> Measurement Uncertainty -> Engineering Assessment`
