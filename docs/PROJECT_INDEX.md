## Milestone-ID Policy

- IDs are stable and never reused.
- Every substantive technical milestone receives an `HV-###` identifier.
- The index is updated before a milestone is merged to `main`.
- Verification IDs such as `DV-001` or `DQ-001` are independent technical gates and are linked to the relevant milestone.
